Interpretació d'un objecte JavaScript

El següent codi defineix un objecte persona amb dues propietats i un mètode:

var persona = {
  "name": "María",
  "edad": 23,
  "avisar": function() {
    alert("Hola soy " + this.name + " y mi edad es " + this.edad);
  }
};

persona.avisar();
Propietats de l'objecte:
• name: María
• edad: 23
• avisar: funció que mostra una alerta amb les dades

Fes clic al botó per executar el mètode persona.avisar():

Mètode executat correctament. S'ha mostrat l'alerta!
